# DICOM Viewer(最終課題)

Axial / Coronal / Sagittal の 3 断面を表示する DICOM ビューアです。
あわせて、第5回で抽出した肺領域(TIFF)を 3D ボリュームレンダリングで表示できます(観点7)。
Python + PySide6(Qt)で自作しています(画像表示用の既成ビューアは使っていません)。

## インストール手順(仮想環境)

このフォルダ(`main.py` がある場所)で実行してください。

### Windows(PowerShell)
```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
PowerShell で `activate` が拒否される場合は `.venv\Scripts\Activate.ps1` を使うか、
`Set-ExecutionPolicy -Scope Process RemoteSigned` を実行してください。

## 操作方法

### ファイルメニュー(観点2)
- **ファイル > DICOM フォルダを開く...**(Ctrl+O): 選んだフォルダ以下(サブフォルダ含む)の DICOM を検索して読み込みます。
  フォルダ内に複数シリーズがある場合は選択ダイアログが出ます。
- **ファイル > DICOM ファイルを選択して開く...**: ファイルを複数選択して読み込みます。
- **ファイル > 終了**

### 3 断面表示(観点1・3)
画面左から Axial(横断)/ Coronal(冠状)/ Sagittal(矢状)を表示します。
画像のピクセル間隔(mm)を考慮して縦横比を保っています。

### 断面位置を示す線(観点4)
他の 2 断面の位置を、その断面を表す色の線で表示します。

| 線の色 | 意味 |
|---|---|
| 赤 | Axial 断面の位置 |
| 緑 | Coronal 断面の位置 |
| 青 | Sagittal 断面の位置 |

例: Axial 画像には「緑の水平線 = Coronal 位置」「青の垂直線 = Sagittal 位置」が表示されます。

### スライダー(観点5・6)
各断面パネルの下に 3 本のスライダーがあります。
- **Slice**: その断面のスライス位置。動かすと、他の 2 画像に描かれた線も連動して動き、他画像の表示スライスも更新されます。
- **WL**(ウィンドウレベル)/ **WW**(ウィンドウ幅): **断面ごとに独立して**調整できます。

### 肺領域の 3D ボリュームレンダリング(観点7)
1. 先に **ファイル** メニューから、肺マスクの元になった CT(DICOM)を開きます。
2. **3D表示** メニューから肺マスク(第5回で抽出した TIFF)を選びます。
   - **肺マスク TIFF ファイルを選んで 3D 表示...**: 全スライスが 1 つに入ったマルチページ TIFF
   - **肺マスク TIFF フォルダ(1スライス1ファイル)を選んで 3D 表示...**: スライスごとの TIFF が入ったフォルダ(ファイル名の数字順に並べます)
3. 別ウィンドウに 3D 表示されます。

マスクの条件:
- 値が 0 のところは背景、0 以外は肺領域として扱います(0/1 でも 0/255 でも可)。
- 画像の大きさ(幅 × 高さ × 枚数)が、開いている CT と**同じ**である必要があります。異なる場合は大きさを示すエラーが出ます。
- スライスの並び(z 方向)が CT と逆の場合は、肺の CT 値が低くなる向きを自動判定して反転します。表示が不自然なときは「マスクの z 方向を反転」で切り替えてください。

3D ウィンドウの操作:
- **表示モード**: 「肺領域の CT(CT 値で着色)」= 肺の内部(血管・結節)を CT 値に応じた色と不透明度で表示 /
  「肺マスクのみ(単色)」= 肺の形状だけを表示
- **不透明度**スライダー: 全体の濃さを調整
- **視点**ボタン: 正面 / 背面 / 右側 / 左側 / 上から / 下から
- マウス: 左ドラッグ = 回転、右ドラッグまたはホイール = 拡大縮小、Shift+左ドラッグ = 平行移動
- 画面右に、肺の体積(mL)も表示します。

### その他の操作
- 画像上を**左クリック/ドラッグ**: その位置が 3 断面の交点になります(クロスヘア)。
- 画像上で**マウスホイール**: その断面のスライスを 1 枚ずつ移動。
- **表示メニュー**: 全ビューの WL/WW をプリセット(軟部組織 / 肺野 / 骨)に変更、スライス位置を中央に戻す。
- 画面下のステータスバーに、現在位置(x, y, z)・CT 値(HU)・画像サイズ・ボクセル間隔を表示します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `main.py` | メインウィンドウ、メニュー、断面間の連動処理 |
| `slice_view.py` | スライス画像の描画ウィジェット、スライダー付きパネル |
| `dicom_loader.py` | DICOM 読み込み(並べ替え・HU 変換・ボクセル間隔計算) |
| `mask_loader.py` | 肺マスク TIFF の読み込み |
| `volume_view.py` | 肺領域のボリュームレンダリング表示(VTK) |
| `requirements.txt` | 使用パッケージ(バージョン固定) |

## 注意事項

- 非圧縮の DICOM(Explicit/Implicit VR Little Endian)を想定しています。
  JPEG 等で圧縮された DICOM は読み込めない場合があります(エラーメッセージが表示されます)。
- スライスは `ImagePositionPatient` と `ImageOrientationPatient` から並べ替えます。
- 3D 表示には OpenGL に対応したグラフィックス環境が必要です。
- 3D 表示で VTK が読み込めない場合も、観点1〜6 のビューア機能は動作します。
- 圧縮された TIFF(LZW など以外の特殊な圧縮)は読み込めない場合があります。その場合はエラーが表示されます。
- 画素値は `RescaleSlope` / `RescaleIntercept` を適用した HU 値として扱います。
